## Evaluation Framework

Compare candidates on:

- License compatibility
- Maintenance activity
- Security posture
- Deployment model
- Data portability
- API and integration support
- Performance
- Documentation
- Community health
- Migration effort
- Total operating cost

The matrix is deliberately non-ranked: the right choice depends on the workload.
