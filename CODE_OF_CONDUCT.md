# Code of Conduct

## Standards

Participants are expected to:

- communicate respectfully;
- focus criticism on ideas and implementations;
- welcome contributors with different skill levels;
- provide actionable technical feedback;
- respect project boundaries and maintainer decisions.

Unacceptable behavior includes harassment, threats, discrimination, deliberate disruption, impersonation, fabricated evidence, and malicious publication of private information.

Maintainers may moderate contributions to protect the project and its participants.
