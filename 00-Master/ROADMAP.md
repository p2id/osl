# Roadmap

## Phase 1 — Foundation

- Keep the vault clean and navigable.
- Establish reusable project templates.
- Standardize architecture and acceptance criteria.
- Create a consistent release process.

## Phase 2 — Project Factory

- Generate project specifications.
- Create repositories from templates.
- Generate task breakdowns.
- Run tests and static checks.
- Produce documentation and release artifacts.

## Phase 3 — Local Automation

- Add local model support.
- Add task queues.
- Add reproducible build environments.
- Add cost and resource accounting.
- Add sandboxed execution.

## Phase 4 — Public Collaboration

- Improve issue templates.
- Add contributor workflows.
- Add project health dashboards.
- Publish postmortems and decision records.
- Make contribution difficulty visible.

## Phase 5 — Scale

- Parallel project execution.
- Automated regression testing.
- Cross-project dependency mapping.
- Shared components and reusable services.
- Optional cloud workers when local capacity is insufficient.
