# Project Lifecycle

```text
IDEA
  ↓
RESEARCH
  ↓
SPECIFICATION
  ↓
PROTOTYPE
  ↓
MVP
  ↓
PUBLIC TEST
  ↓
DECISION
 ├── CONTINUE
 ├── SCALE
 ├── PIVOT
 ├── FREEZE
 ├── OPEN
 └── ARCHIVE
```

## Continue

The project has useful evidence and a clear next milestone.

## Scale

The project has demonstrated sufficient value and requires more capacity.

## Pivot

The original problem or implementation needs to change.

## Freeze

The project remains available but active development stops.

## Open

The project is released with complete documentation and a postmortem where appropriate.

## Archive

The project is preserved for reference when continued maintenance is not justified.
