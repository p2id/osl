# Open Software Lab

A public, open-source knowledge base and build laboratory for software, tools, services, infrastructure, and AI-enabled systems.

## Mission

Build useful software in small, testable units. Prefer local ownership, transparent architecture, portable data, replaceable components, and reproducible deployment.

The laboratory supports two parallel tracks:

1. **Traditional software** — deterministic foundations, explicit rules, tests, performance, reliability, and maintainability.
2. **AI-enhanced software** — a reliable software foundation with an optional AI layer using local models or external APIs.

## Lifecycle

`IDEA → RESEARCH → SPECIFICATION → PROTOTYPE → MVP → PUBLIC TEST → DECISION → SCALE / PIVOT / FREEZE / OPEN / ARCHIVE`

## Public Principles

- Build small, useful projects.
- Keep core functionality independent of optional AI.
- Prefer self-hosting and data portability.
- Make failures useful by documenting what was learned.
- Accept contributions from beginners through experienced engineers.
- Use reproducible builds and automated tests.
- Do not fabricate users, feedback, metrics, or community activity.
- Respect platform rules and API terms.
