# Build Lab — Project Portfolio

A portfolio of independent software projects, ordered by domain and numbered for tracking.

## Project Principles

- Small first releases.
- Clear acceptance criteria.
- Reproducible builds.
- Local-first where practical.
- AI is optional unless the product explicitly requires it.
- Every project can be continued, frozen, pivoted, opened, or archived.
