# Quality Gates

## Gate 0 — Idea

Required:

- concrete problem;
- target users;
- expected outcome;
- reason the project should exist.

## Gate 1 — Specification

Required:

- scope;
- non-goals;
- architecture;
- data model;
- acceptance criteria;
- risks.

## Gate 2 — Prototype

Required:

- runnable core flow;
- basic error handling;
- reproducible setup.

## Gate 3 — MVP

Required:

- automated tests;
- documentation;
- installation instructions;
- logging;
- security baseline.

## Gate 4 — Public Release

Required:

- version;
- changelog;
- license;
- known limitations;
- issue templates;
- rollback or recovery procedure where applicable.

## Gate 5 — Continuation

Use real evidence:

- activation;
- repeat usage;
- retention;
- reliability;
- support burden;
- operating cost;
- contribution activity.

Do not use vanity metrics as the sole decision criterion.
