# Distribution Principles

## Build Distribution Into the Product

A useful project naturally creates artifacts that can be shared:

- README;
- demo;
- screenshots;
- benchmarks;
- tutorials;
- changelog;
- architecture notes;
- failure reports;
- release notes;
- examples.

## Community Discovery

Adapt communication to each community. Do not post identical promotional material everywhere.

Prioritize:

1. useful technical information;
2. genuine project progress;
3. real lessons from failures;
4. practical examples;
5. questions that invite informed discussion.

## Trust

Never fabricate:

- users;
- comments;
- testimonials;
- benchmarks;
- repository activity;
- contributor identities;
- market demand.

Growth should come from useful work and authentic participation.
