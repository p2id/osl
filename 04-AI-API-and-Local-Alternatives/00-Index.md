# AI, API, and Local Alternatives

A catalog of AI-enhanced software patterns that can be implemented with local models, external APIs, or both.

## Design Principle

AI should be an optional capability layered on top of a deterministic software foundation whenever the core workflow does not require machine learning.

## Safety Boundary

Systems that affect real-time control, boot processes, drivers, hypervisors, or other safety-critical infrastructure require deterministic safeguards, simulation, explicit policy constraints, and human oversight. AI suggestions must not silently override safety controls.
